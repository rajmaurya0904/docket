# Changelog
All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-18
### Added
- `docket build`, `docket check` and `docket serve` commands.
- Dependency-free Markdown compiler (headings, lists, tables, code, quotes, task lists).
- Flat frontmatter parser with `title`, `description` and `order`.
- API endpoint detection from `METHOD /path` headings and `api` fenced blocks, with
  a client-side "Try it" explorer, `curl` preview and JSON example validation.
- Link rewriting and checking for pages, fragments and copied static files.
- Responsive light and dark layout, on-page contents and in-browser search.
